# Assets da landing page

Adicione aqui os arquivos oficiais, mantendo exatamente estes nomes:

- `logo.svg` — logo autorizada da Academy;
- `founder.jpg` — foto do fundador;
- `proof-01.jpg` — prova/reunião;
- `proof-02.jpg` — prova/validação;
- `proof-03.jpg` — prova/certificado;
- `vsl-thumbnail.jpg` — thumbnail da VSL.

Enquanto as imagens não existirem, a interface mostra placeholders neutros. Não adicione provas, marcas ou resultados sem autorização.
